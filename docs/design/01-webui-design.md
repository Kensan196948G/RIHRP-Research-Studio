## 2. 利用者と主要フロー

| 役割 | 主な操作 |
|---|---|
| viewer | 閲覧のみ |
| editor（リサーチャー） | テーマ・出典・主張・根拠・レポートの編集、検証、提出 |
| reviewer（レビュアー） | 承認・差し戻し、監査ログ閲覧 |
| admin（管理者） | 利用者管理、全操作 |

主要フロー: ログイン → ダッシュボード → テーマ → 出典登録（SHA-256）→ 主張 + 根拠 → 検証 → レポート編集 → 検証 → 提出 → レビュー（承認 / 差し戻し）→ Markdown エクスポート。

## 3. 画面一覧

1. **ログイン** — メール + パスワード。左に価値説明、右にフォーム。開発時のみデモアカウントを表示。
2. **ダッシュボード** — 研究テーマ一覧。上部に 4 指標（テーマ / 未検証 / 矛盾 / レビュー待ち・差し戻し）。行クリックでテーマへ。
3. **テーマ詳細（概要）** — タイトル・概要・状態、4 指標、次にやること、テーマ情報、一括検証。
4. **テーマ詳細（出典）** — 出典テーブル（種別・識別子・SHA-256 短縮・参照数・改竄バッジ）、出典詳細モーダル（本文・完全ハッシュ・整合性）、登録モーダル。
5. **テーマ詳細（主張）** — 主張テーブル（判定バッジ・根拠数・最終検証）、詳細モーダル（根拠一覧・引用の実在・数値の一致・理由）、根拠追加モーダル、検証。
6. **テーマ詳細（レポート）** — レポートテーブル（状態・版・参照主張・提出者）、作成、エディタへ。
7. **レポートエディタ** — 左: セクション / 段落編集・主張チップ、右: 検証サマリ・主張パレット・版とシール・レビュー履歴。上部: 保存 / 検証 / 提出 / Markdown。
8. **レビュー** — レポートエディタ下部（レビュー中のみ）。コメント、承認、差し戻し。矛盾がある場合は承認不可の理由を表示。
9. **監査ログ / 利用者管理** — 監査イベント（時刻・実行者・操作・対象・詳細）、利用者の作成・有効化 / 無効化。

## 4. デザイン方針（OpenDesign `tech-utility` 準拠）

- 基調: 白（`#ffffff`）+ 濃紺テキスト（`#0f2436`）+ ティールのアクセント（`#0f766e`）。
- 情報密度: 高め。ヘアライン罫線のテーブル、行ストライプなし、`font-variant-numeric: tabular-nums`。
- コード / ID / ハッシュ: 等幅（`JetBrains Mono` 系）。
- ステータス: 抑制された淡色背景 + 小さなドット + テキスト。
  - verified = 緑 / unverified = 黄 / contradicted = 赤 / insufficient = 灰。
- 角丸 10px、影は弱く（1 段）、カードは境界線で分離。
- 過剰なヒーロー画像・ marketing コピーを置かない（utility の posture）。

## 5. 状態設計

| 画面 | loading | empty | error | success |
|---|---|---|---|---|
| ログイン | 送信中表示 | — | 認証失敗バナー | ダッシュボードへ遷移 |
| ダッシュボード | スピナー + テキスト | 「テーマがまだありません」+ 作成 | バナー + 再試行 | テーマ表 |
| テーマ | スピナー | タブごとの空状態 | バナー + 再試行 | 各タブ |
| 出典登録 | 登録中 | — | 409/422 をトースト | 成功トースト + 一覧更新 |
| 主張検証 | 検証中 | 根拠 0 は「根拠不足」 | トースト | バッジ更新 |
| レポート | 読み込み | セクション 0 の案内 | バナー | 保存済み / 未保存バッジ |
| 承認 | 承認中 | — | 矛盾理由（409） | 承認済み表示 |
| 監査 | スピナー | 「該当する履歴がありません」 | バナー + 再試行 | 一覧 |

## 6. 権限と表示制御

- 編集系ボタンは `editor` / `admin` のみ表示。viewer は閲覧のみ。
- レビュー欄は `reviewer` / `admin` かつ `in_review` のときだけ表示。
- 承認は提出者本人には 403（UI はエラーを表示）。
- 監査ログは `reviewer` / `admin`、利用者管理は `admin` のみナビに表示。

## 7. レスポンシブ / アクセシビリティ

- 1440px を基準。1100px で右パネルを 300px に、900px でサイドバーをアイコンのみに、640px で 1 カラム。
- モバイルは閲覧中心（編集は可能だが表は横スクロール）。
- `:focus-visible` に 2px のティールリング。モーダルは Esc で閉じ、初期フォーカスを内部へ移す。`aria-modal` / `role="dialog"` / `aria-live` を使用。
- 色だけで状態を伝えない（バッジはテキストを持つ）。

## 9. 受入条件

- 主要フローが UI で完走する（実測: 2026-11-02、editor 提出 → reviewer 承認 → Markdown エクスポート）。
- 矛盾（改竄）時に承認が拒否され、理由が表示される。
- 各画面に loading / empty / error のいずれかが実装されている。
- 権限外の操作が UI に出ない、または API で 403 になる。
