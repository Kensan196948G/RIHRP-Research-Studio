# 02. 詳細テスト仕様 — Offline Research Studio WebUI（100% 整合）

- 版: v1.0（2026-11-03）
- 正本: [`RIHRP_Offline_Research_Studio.html`](../../RIHRP_Offline_Research_Studio.html) と [`docs/design/02-offline-studio-spec.md`](../design/02-offline-studio-spec.md)
- 対象: 認証後の WebUI（6 ビュー）＋研究文書 API＋保存/復元/エクスポート
- 方針: 期待値は原則プロトタイプと同一。差異が出る場合は「プロトタイプを正」とし、実装を修正する。

## 0. 実行方法と証跡

| 種別 | 方法 | 証跡 |
|---|---|---|
| API | `pytest`（実 PostgreSQL `rihrp_test*`） | テスト名・実行ログ・DB 行 |
| UI | Playwright（headless Chromium、1280×900 と 390×844） | 画面キャプチャ `docs/assets/screenshots/offline-studio-*.png` |
| 状態遷移 | Playwright（タスク実行・承認・討論再生） | スクリーンショット＋再生ログ |
| 静的 | `tsc -b` / `vite build` / `ruff` / `openapi --check` | CI ログ |

- 結果は本ファイルの「状態」列を `未実行` → `PASS` / `FAIL(理由)` に更新し、実行日時と実行者（AI/人間）を記録する。
- 各 FAIL には再現手順と実際の結果を追記する。
