# ADR-0002: 検証は決定論的アルゴリズムで行い、LLM に判定を委ねない

- 状態: 提案
- 日付: 2026-11-02

## 背景

「根拠に基づく」と言いながら、判定が生成モデルの気分に依存すると、監査も再現もできない。承認の条件を機械的に説明できる必要がある。

## 決定

主張の検証は次のみで判定する。

1. 出典本文の SHA-256 再計算（完全一致）
2. 引用文字列の実在確認（空白正規化後の部分一致）
3. 主張中の数値トークンの実在確認

判定は `verified` / `unverified` / `contradicted` / `insufficient` の 4 値。LLM は判定に使わない。

## 理由

- 同じ入力に対して常に同じ出力になり、テストで固定できる。
- 「なぜ未検証か」を人間に説明できる（quote_not_found / number_not_found / no_anchor / evidence_tampered）。
- 承認条件（contradicted = 0）が機械的に検査できる。

## 影響

- 言い換え（paraphrase）や含意の検証はできない。MVP では「引用を付ける」運用でカバーする。
- 数値の表記揺れ（1,000 と 1000）は別物として扱う。必要なら正規化規則を追加する ADR を起こす。

## 代替案

- LLM による含意判定: 再現性・監査性が落ちるため、判定には使わない（将来、参考情報として別フィールドに出すのは可）。
