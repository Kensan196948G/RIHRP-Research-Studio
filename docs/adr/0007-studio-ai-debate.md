# ADR-0007: スタジオ AI 討論（生成のみ・討論だけ・既定 OFF）

- 状態: 採用（PoC）
- 日付: 2026-11-13
- 関連: [ADR-0002](0002-deterministic-verification.md) / [ADR-0006](0006-ai-drafting.md) / [Phase 3 B 設計](../design/03-studio-llm-replacement-plan.md) / [AI 討論テスト計画](../testing/06-ai-debate-test-plan.md)

## 背景

スタジオの「AI エージェント」はブラウザ内のルールベース処理で、同一入力に同一出力を要求している
（[design/02](../design/02-offline-studio-spec.md) §4・§6）。Phase 3 B ではこの一部を外部 LLM に
置き換えるかを検討し、設計・リスク評価の結果、**討論（03）だけを対象**にした PoC を実装した。

決定論的検証（ADR-0002）は維持する。既存の LLM 基盤（ADR-0006）を再利用し、鍵・監査・
フェイルクローズの扱いを揃える。

## 決定

1. **対象は 03 討論の生成のみ**。検証・信頼性スコア・候補採点・採択は決定論のまま変更しない。
2. **assist 方式・既定 OFF**。`RIHRP_LLM_*` が未設定なら 503 `ai_not_configured` で機能だけ止め、
   既存機能は通常どおり動く。**生成操作そのものを opt-in** とし、プロジェクト設定の追加はしない。
3. **生成物は保存しない**。サーバーは `messages[]` と provenance を返すだけ。
   利用者がプレビューを確認して「採用」したときだけ、研究文書に保存する。
4. **保存時は provenance を付ける**（provider / model / promptVersion / generatedAt）。
   UI は「AI 生成」であることを明示する。
5. **引用は既存 evidence ID のみ**。AI が存在しない ID を出した発言は採用しない
   （捏造引用の入口で落とす）。自由文の文献名・数値は検証也不能として扱う。
6. **入力は研究文書の限定フィールド**（仮説・資料 8 件・批判 6 件）に絞り、
   上限・タイムアウト・レート制限は既存の `RIHRP_LLM_*` を流用する。
7. **監査**は `ai.debate_requested` に provider / model / promptVersion / 件数 / latency を残し、
   プロンプト本文・生成本文・鍵は残さない。
8. **承認の自動化はしない**。討論の採用は研究者の操作で、既存の承認フローとは独立。

## 理由

- 討論はレポートの文章と UI にしか影響せず、スコア・検証・採択を汚さないため、決定論の境界を
  保ったまま LLM の品質・幻覚・コストを評価できる。
- 生成物を保存しないことで、幻覚やプロンプトインジェクションがそのまま研究データに
  固定化されるのを防ぐ（ADR-0006 と同じ設計）。
- 既定 OFF・server 設定必須により、キー未投入の環境では外部通信が発生しない。

## 影響

- 追加 API: `POST /api/projects/{id}/ai/debate`（editor 以上）。
- UI: 03 に「✦ AIで討論を生成（試行）」、プレビュー、採用 / 破棄、AI 生成ラベル。
- 保存形式: `debate[]` に `evidenceIds`、`debateAi` に provenance を追加。
- テスト: スタブによる API 11 件・E2E 1 件。実キーでのスモークは人間承認後に別途。
- 未実装: 中断時の自動クリーンアップ、自動品質ゲート、B 案の他工程（批判・候補）への拡大。

## 代替案

- 全工程を LLM に置換: 検証・採点まで非決定になり、ADR-0002 と両立しないため不採用。
- 生成物を即時保存: 幻覚の固定化を招くため不採用。
- ブラウザから直接 LLM を呼ぶ: 鍵が配布物に載るため不採用（ADR-0006 と同じ）。

## 実キー canary（2026-11-13）

隔離 DB・3 リクエストで実施し、G1（捏造引用 0・注入拒否）/ G2（検証前後一致）/ G4（監査に本文・鍵なし）を PASS。
G5 は 2 名評定（2 名目は AI 再評定・独立性限定的）で全次元「十分」、Q6 は既定案で確定。詳細: [canary 記録](../verification/2026-11-13-ai-debate-canary.md)。
