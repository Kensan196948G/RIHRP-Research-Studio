# ADR-0003: 承認は「矛盾ゼロ」を必須とし、未検証件数を明示する

- 状態: 提案
- 日付: 2026-11-02

## 背景

レビュー承認が「読んだ」の意味しか持たないと、根拠の無い記述が承認済みとして流通する。一方で、すべてを verified にしないと承認できない設計は、現実の調査（一次情報が取りにくい）で運用が止まる。

## 決定

- レポート承認（`approved`）の条件は **contradicted = 0** とする。
- `unverified` / `insufficient` は承認をブロックしないが、承認 API の応答と UI に件数を必ず表示し、エクスポートにもマーカーを残す。
- 提出者本人は承認できない（職務分離）。
- 差し戻しはコメント 10 文字以上を必須とする。

## 理由

- 矛盾は「根拠と食い違う」= 品質の重大な欠陥であり、止める価値がある。
- 未検証は「根拠が薄い」であり、承認判断は人間に残す。ただし可視化は強制する。
- 承認者と提出者の分離により、自己承認を防ぐ。

## 影響

- 承認 API は 409 `approval_blocked` を返す場合がある。UI は矛盾一覧へのリンクを出す。
- 既存の承認済みレポートの主張を後から編集した場合、版が変わるため再承認が必要（版番号で管理）。

## 代替案

- verified のみ承認可: 一次情報が取れない調査で運用不能になるため不採用。
- すべて人間判断: 矛盾の見落としを防げないため不採用。
