# RIHRP Research Studio v0.1.0 — リリースノート

- リリース日: 2026-11-03
- 対象: `main`（タグ `v0.1.0`）
- 公開 URL: `https://research.mirai-dx-platform.com`（Cloudflare Access 保護）

## 概要

根拠付きの研究ワークフロー（研究仮説 → AI タスク → 複数 AI 討論 → 根拠・反証 → 新仮説比較 → 研究報告書）を、
決定的な検証（引用の実在・SHA-256・承認ルール）と監査ログ付きで提供する初回リリース。

## 主な機能

- 認証・セッション・CSRF・RBAC（admin / editor / reviewer / viewer）
- 出典（SHA-256）・主張・根拠・検証・レポート・版・提出・承認・差し戻し・エクスポート
- Offline Research Studio の 6 ステップ UI（サーバー永続化、オフライン保存失敗からの復帰）
- Cloudflare Access JWT による自動ログイン（単一 email、fail closed）
- 320px〜デスクトップのレスポンシブ、キーボード操作、ダークモード、印刷
- 監査ログ（append-only、TRUNCATE 保護）と監査統計コマンド

## 既知の制約

- Access 認証後の実ブラウザ確認（OTP/SSO）と、実機・スクリーンリーダーは人手での確認が必要。
- 外部合成監視とアラート配信先は未設定（`RIHRP_ALERT_WEBHOOK` を設定すると webhook 通知）。
- 監査ログの保持期間削除ジョブは未実装（方針決定後に追加）。
- CI への E2E・依存監査ジョブは提案ドキュメントのみ（`.github/workflows/**` は人間が適用）。
